使用说明
  1. 打开终端页面（JumpServer Web 终端 / Arthas Console），完成连接
  2. 点「🔍 捕捉终端」（灰点变绿）。多开时在下方选目标 tab
  3. 点「🚀 启动代理」（橙点变绿）
  4. 两个都绿，Agent 即可通过桥接发命令
⚠ 交互式命令（vim/less/需密码的 sudo）会超时
⚠ Arthas 高风险命令（retransform/profiler/stop/reset）已禁用
